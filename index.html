Política de Privacidad de Rifalo

Fecha de entrada en vigencia: 29 de abril de 2026

Rifalo es una aplicación móvil para crear y administrar rifas de forma sencilla. Esta Política de Privacidad explica qué información puede usar la aplicación, para qué se usa y cómo se protege.

Información que la aplicación puede usar

Contactos

Rifalo puede solicitar acceso a tus contactos para ayudarte a asignar rápidamente números de una rifa a una persona. La información de contactos se usa dentro de la aplicación para facilitar la organización de la rifa.

Rifalo no vende tus contactos.

Imágenes o galería

Rifalo puede solicitar acceso a imágenes del dispositivo para permitirte seleccionar una imagen representativa de una rifa.

Cámara

Si la aplicación o el sistema solicita acceso a la cámara, este permiso se usa únicamente para permitir funciones relacionadas con la selección o captura de imágenes para la rifa. Rifalo no usa la cámara para vigilancia, grabación en segundo plano ni recopilación no autorizada.

Internet

Rifalo usa conexión a Internet para funciones relacionadas con anuncios, servicios externos, configuración remota, compras o funcionalidades necesarias para operar la aplicación.

Anuncios e ID de publicidad

Rifalo puede mostrar anuncios mediante servicios de terceros como Google AdMob. Estos servicios pueden usar el ID de publicidad del dispositivo para mostrar anuncios, medir rendimiento, prevenir fraude y cumplir requisitos de seguridad.

Firebase y configuración remota

Rifalo puede usar Firebase u otros servicios similares para configuración remota, monitoreo básico o control de funciones de la aplicación, por ejemplo activar o desactivar anuncios.

Compras o suscripciones

Rifalo puede ofrecer funciones premium o compras dentro de la aplicación. Estas transacciones pueden ser procesadas por Google Play u otros proveedores de servicios de pago. Rifalo no almacena directamente los datos completos de tarjetas de pago.

Cómo se usa la información

  • Crear y administrar rifas.
  • Asignar participantes a números.
  • Seleccionar imágenes relacionadas con rifas.
  • Mostrar anuncios.
  • Gestionar funciones premium.
  • Mejorar la estabilidad y funcionamiento de la aplicación.
  • Cumplir requisitos legales, de seguridad y de plataforma.

Compartir información con terceros

Rifalo puede interactuar con servicios de terceros necesarios para operar la aplicación, como Google AdMob, Firebase, Google Play y servicios de gestión de compras si están habilitados. Estos servicios pueden procesar datos de acuerdo con sus propias políticas de privacidad.

Retención de datos

Rifalo conserva información solo durante el tiempo necesario para ofrecer sus funciones o cumplir obligaciones técnicas, legales o de seguridad. Parte de la información puede almacenarse localmente en el dispositivo.

Seguridad

Rifalo busca proteger la información del usuario usando prácticas razonables de seguridad. Sin embargo, ningún sistema digital puede garantizar seguridad absoluta.

Privacidad de menores

Rifalo no está dirigida específicamente a niños pequeños ni busca recopilar intencionalmente información de menores sin consentimiento apropiado. Si crees que se ha recopilado información de forma incorrecta, puedes contactarnos para revisarlo.

Derechos del usuario

Dependiendo de tu ubicación, puedes tener derecho a solicitar acceso, corrección o eliminación de ciertos datos personales. También puedes revocar permisos desde la configuración del dispositivo Android.

Cambios a esta política

Esta Política de Privacidad puede actualizarse ocasionalmente. Las actualizaciones se publicarán en esta misma página con una nueva fecha de vigencia.
